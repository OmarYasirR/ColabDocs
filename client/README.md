# Collaborative Document Editor

This is a collaborative document editing application built with React, Redux Toolkit, Tailwind CSS, and Socket.io.

## Features

- User Authentication (Login/Register)
- Document Management (Create, Edit, Delete)
- Real-time Collaboration (Cursors, Comments)
- Responsive Design

## Tech Stack

- React 18
- Redux Toolkit
- React Router v6
- Tailwind CSS
- Socket.io Client
- Axios
